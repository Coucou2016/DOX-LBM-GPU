## 8. How a third party should reproduce the headline numbers

1. Clone the repo at the audited SHA (or later commit that preserves the CSV/JSON above).
2. Install dependencies; set `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`; run `pytest` → expect all green.
3. Confirm `outputs/phase_diagram_summary.json` (or regenerate with `run_phase_diagram.py --full`) shows `n_va_paper=1`, `n_va_recurrence=3`, `n_va_strict=1`.
4. Confirm `ms_0d_summary.json` APD ≈ 256.6 ms and validation CV ≈ 0.703 mm/ms.
5. Run `plot_science.py` and `build_research_report.py` / `build_manuscript_html.py` to refresh figures and HTML.

If any table number in the manuscript cannot be traced to a file in §5, treat it as an authoring error—not as an external result.
